# Agent Note: 在一个组合包中保留追踪记录与本地可视化

Status: implemented

[English](2026-08-18-local-trace-viewer.md) | 中文

## 问题

Agent Run Logger 需要实用的可视化检查界面，但不能把本地诊断追踪变成远程服务，也不能让记录过程依赖 Viewer 进程。持续增长的 JSONL 文件、并发 Session 和可选内容采集还要求内存有界，并明确文件系统与网络安全规则。

## 决策

`dsh-agent-run-logger` 保持为一个 npm 组合包。Cordis 插件把已提交的 Session 事件投影到各 Session 独立的 JSONL 文件；同一包中的 CLI 为这些文件提供独立的只读 Viewer。记录过程不依赖 CLI；除非用户明确开启保留期删除，否则 CLI 不写入追踪数据。

Repository 增量索引已完整追加的行，只在内存中保留摘要和字节偏移，而不是完整记录。分页请求重新打开已索引的普通文件，并在读取前校验文件身份。文件缩短或身份替换会让浏览器重置对应 Session；普通追加则从现有游标继续。父子 Session 保持独立时间线，并通过已记录的父子关系连接。

HTTP Server 只监听回环地址、校验 Host Header、仅公开封闭的 GET 路由集合、限制记录页和 SSE 订阅者数量，并断开慢速订阅者。启动、轮询和释放过程各有唯一的自有 Promise，使并发生命周期操作最终完全停止。内容采集保持显式开启；开启后，配置的凭证类值会在有界 UTF-8 截断及持久化之前完成脱敏。

## 曾考虑的替代方案

**拆分第二个 Viewer 包**：否决。Logger Schema、安装 Patch、CLI、静态资源和发布版本需要作为一个可安装的 DeepSeek Harness 插件共同保持兼容。

**在浏览器或 Server 中加载整个追踪文件**：否决。追踪文件持续增长，多个 Session 也可能并发运行；增量偏移限制 Server 内存，分页读取限制每次响应大小。

**带认证的远程监听**：本版本否决，因为它会扩大威胁模型和部署范围。Viewer 被明确限定为本地诊断工具。

**只在 UI 脱敏**：否决，因为敏感值届时已经写入磁盘。因此脱敏在记录路径中发生，早于截断和持久化。

## 后果

用户只需安装和升级一个包，就能检查实时及历史本地追踪，而不改变 Agent 执行。该设计放弃远程访问、跨 Session 合并时间线、数据库、上传和 OpenTelemetry 导出。追踪文件仍是诊断数据而非规范 Session 日志；脱敏能减少凭证意外采集，但不承诺识别所有秘密。
